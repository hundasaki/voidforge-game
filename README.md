# ⚡ VOID FORGE ⚡

A cyberpunk-themed space shooter game built with vanilla JavaScript and HTML5 Canvas.

## 🎮 How to Play

- **Arrow Keys** or **WASD** - Move your ship
- **SPACEBAR** - Shoot
- **Objective** - Destroy all enemies and survive!

## 🚀 Play Now

Visit: **https://hundasaki.github.io/voidforge-game/**

## 📊 Game Features

- **Dynamic Enemy Spawning** - Enemies appear gradually, up to 10 at a time
- **Health System** - Start with 100 HP, lose 10 per enemy collision
- **Scoring** - Earn 10 points per destroyed enemy
- **Neon Aesthetic** - Cyberpunk glowing effects
- **Smooth Gameplay** - 60 FPS animation

## 🛠️ Technical Details

- **No Dependencies** - Pure JavaScript, no libraries required
- **Responsive Canvas** - Adapts to different screen sizes
- **Collision Detection** - AABB system
- **Performance Optimized** - RequestAnimationFrame for smooth rendering
